# Nav-Site · 1Panel 本地应用

自托管导航与书签管理，支持后台维护导航内容和上传文件。

## 镜像与环境

- 上游项目：<https://github.com/shenbourne/Nav-Site>
- 镜像：`shenbourne/nav-site:latest`（Docker Hub）
- 镜像架构：amd64，按发布时 Docker Hub 的 `latest` 清单核对；不包含证明用的 `unknown/unknown` 清单。
- 容器内端口：`3000`；默认主机端口：`3000`。
- 依赖 Docker 外部网络 `1panel-network`，缺少时先创建。

`latest` 为可变标签，模板不会锁定镜像内容。升级前请备份并检查上游变更。

## 安装与访问

同步商店后在 1Panel 本地应用中刷新并安装。安装表单中可调整 `PANEL_APP_PORT_HTTP` 和 `APP_BIND_IP`。

默认监听 `0.0.0.0`，通过 `http://服务器地址:3000` 访问（修改端口后相应调整）。首次管理员用户名为 `admin`，安装时填写至少 12 位初始密码 `NAV_ADMIN_PASSWORD`。此变量仅在首次创建账号时使用，后续修改表单不会重置已有密码，请在应用中修改。

直连时 `TRUST_PROXY` 留空；使用一层可信反向代理时填写 `1`，不要无条件信任客户端伪造的转发头。JWT 密钥由服务自动生成并保存在数据目录，不在模板中提供固定密钥。

## 持久化与备份

`./data` 挂载到 `/app/data`，包含导航内容、认证配置和上传文件。停止应用后备份安装目录中的整个 `data` 目录；恢复时保留文件权限。不要将不同实例指向相同目录。
