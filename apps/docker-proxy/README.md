## 产品介绍

**Docker Proxy** 是自建的 Docker 镜像加速与管理服务，可将 Docker Hub、GHCR、Quay、K8s、MCR、Elastic、NVCR 等公共仓库的拉取请求按 Host 自动路由并流式转发，同时提供 HubCMD-UI 可视化管理面板。

## 主要功能

- **零磁盘缓存**：单进程按 Host 自动路由到各大公共仓库，服务端完成 token 鉴权并以流式转发，不落盘、不占用本地存储。
- **多仓库镜像加速**：支持 Docker Hub、GHCR、Quay、K8s Registry、MCR、Elastic、NVCR 等主流镜像仓库的加速与统一管理。
- **上游账号认证**：可配置上游仓库账号密码，由代理服务端换取 Bearer Token，从而拉取 Docker Hub 私有镜像并缓解官方限流。
- **HubCMD-UI 管理面板**：网页端增删改代理、调整服务器参数并热重载，含镜像搜索、文档教程、容器管理与监控告警。
- **系统看板与流量监控**：实时监控服务器资源、容器运行状态与网络流量，并提供镜像拉取的客户端侧流量指标与阈值告警。
- **IP 访问控制**：支持 IP 黑白名单，可针对单个 IP 或 CIDR 网段控制谁能通过本服务拉取镜像。
