## Introduction

**Clash Meta** is a rule-based tunnel powered by the mihomo kernel, with the built-in metacubexd dashboard.

## Features

- **Rule-based Routing**: Forwards packets to different nodes based on domain, GEOIP, IPCIDR, or process rules.
- **Multi-protocol Support**: Supports VMess, VLESS, Shadowsocks, Trojan, Snell, TUIC, and Hysteria.
- **Built-in DNS Server**: A built-in DNS server with DoH/DoT upstream and fake-ip to reduce DNS pollution.
- **Web Dashboard**: Bundled metacubexd dashboard for live traffic, proxy groups, connections, rules, and logs.
- **HTTP API**: A comprehensive HTTP RESTful API for third-party dashboards and automation.
