## 产品介绍

**Clash Meta** 是基于 mihomo 内核的规则代理服务，并内置 metacubexd 控制面板。

## 主要功能

- **规则分流**：支持按域名、GEOIP、IPCIDR 或进程规则将流量转发到不同节点。
- **多协议支持**：支持 VMess、VLESS、Shadowsocks、Trojan、Snell、TUIC、Hysteria 等协议。
- **内置 DNS 服务**：内置 DNS 服务器，支持 DoH/DoT 上游、fake-ip，降低 DNS 污染影响。
- **Web 控制面板**：内置 metacubexd 面板，可实时查看流量、管理策略组与连接、查看规则与日志。
- **HTTP API**：提供完整的 HTTP RESTful API，便于接入第三方面板与自动化工具。
